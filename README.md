# AMR Project - Robot Software

This repository contains the main software for the autonomous mobile robot, running on a Raspberry Pi with ROS (Robot Operating System). It includes:

- Robot navigation and obstacle avoidance
- Object recognition via onboard camera
- Global mapping and path planning
- Integration with ROS nodes and topics

## Requirements
- ROS 2 Jazzy
- OpenCV
- Python 3
- Ubuntu Server 24.04

## Structure
- `/src`: ROS packages and scripts
- `/launch`: Launch files for simulation or hardware
- `/config`: Parameter and calibration files
